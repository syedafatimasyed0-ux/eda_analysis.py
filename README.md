# SWYNEX - Task 3: Interactive Dashboard

## Overview
This repository contains the documentation and design details for Task 3 (Interactive Dashboard) of the Data Analyst Internship at **SWYNEX Technologies**.

## Dashboard Components Built
- **KPI Cards:** Total Employees, Average Salary, and Median Age metrics.
- **Visual Charts:** 
  - Bar Chart: Average Salary per Department.
  - Pie Chart: Department-wise workforce distribution.
- **Interactive Filters:** Department and Date filters for dynamic data slicing.

## Tools Used
- Power BI / Excel / Tableau
